# خطوة بطل — Khatwat Batal

تطبيق شخصي للهاتف، بالعربية ومن اليمين إلى اليسار. فيه تحديات حياتية يحددها المستخدم، ومتجر جوائز شخصية يُشترى بالـCoins، ومجموعة أبطال وزعماء، ولعبة بطاقات تكتيكية. هذه النسخة ويب PWA تعمل في Chrome، وتُثبَّت على الهاتف، وتعمل دون إنترنت بعد تنزيل صور اللعبة.

- كل البيانات تبقى على الجهاز في IndexedDB. لا توجد حسابات ولا خادم ولا مزامنة سحابية.
- الأصول الأصلية (65 صورة PNG) موجودة في `public/assets/` دون أي تعديل. أما `public/assets-display/` فنسخ WebP أصغر مطابقة بصريًا، تُستعمل للعرض الصغير.

## المتطلبات

- Node.js 20 أو أحدث (جُرّب على 22.22)، وnpm 10.
- للاختبارات الطرفية: Chromium الذي يثبّته Playwright (`npx playwright install chromium` على جهازك).

## الأوامر

```bash
npm ci                 # تثبيت الاعتماديات من lockfile
npm run dev            # خادم تطوير (بلا Service Worker)
npm run build          # فحص بصمات الأصول + فحص الأنواع + بناء الإنتاج في dist/
npm run preview        # تشغيل نسخة الإنتاج على http://localhost:4173
npm test               # اختبارات الوحدة (المحرك القتالي، التقدم، التخزين، الكتالوج)
npm run test:e2e       # اختبارات الواجهة وoffline في Chromium (تبني الخادم تلقائيًا عبر preview)
npm run typecheck      # فحص الأنواع فقط
npm run verify:assets  # يتحقق من 65 صورة أصلية مقابل SHA-256 في asset-sources/asset-manifest.json
npm run assets:prepare # يعيد توليد نسخ العرض WebP وفهرس الأصول (بعد إضافة صور جديدة)
```

شغّل `npm run build` قبل `npm run test:e2e` لأن الاختبارات الطرفية تعمل على نسخة الإنتاج.

## البنية

```
src/
  catalog/        الكتالوج الثابت: الأبطال والزعماء والقدرات (أوصاف تأثيرات typed) والقصص وخريطة فتح الزعماء
  engine/
    progression.ts  مستويات الحساب والرتب والجواهر واستحقاقات الزعماء (أعداد صحيحة، مشتقة من XP)
    economy.ts      جدول الصعوبات وقواعد الإكمال والمستوى التجميلي
    dates.ts        التاريخ المحلي (localDateKey) ومنتصف الليل
    rng.ts          مولد قابل للبذر + Fisher–Yates بلا انحياز
    battle/         محرك قتال نقي: resolveSlot/endOfRound/executeRound + سجل أحداث
  store/          IndexedDB: المخازن، المعاملات الذرية، دفتر العمليات، المهاجرات، النسخ الاحتياطي ZIP
  audio/          أصوات مولدة محليًا (WebAudio) ومشغل موسيقى واحد
  pwa/            Service Worker، تنزيل الأصول مع التقدم، التحديث الآمن
  ui/             الصفحات الأربع، الإعدادات، السجل، الساحة، المؤثرات
tests/unit/       اختبارات Vitest (منها 31 حالة قتال مرجعية)
e2e/              اختبارات Playwright
asset-sources/    manifest الأصلي للحزم السبع (بصمات SHA-256)
docs/             دليل الاستعمال، دليل إضافة المحتوى، تقرير الاختبار، والمواصفات الأصلية
```

## النشر على HTTPS والتثبيت على الهاتف

تثبيت PWA يحتاج أصل HTTPS صالحًا. فتح `index.html` مباشرة لا يكفي، و`localhost` على حاسوب آخر لا يصل إليه الهاتف.

1. ابنِ النسخة: `npm ci && npm run build`، أو استعمل ملف `khatwat-batal-web-build.zip` الجاهز (محتوى `dist/`).
2. انشر محتوى `dist/` على أي استضافة ثابتة تعطي HTTPS. كل المسارات نسبية، فالنسخة تعمل من جذر النطاق أو من مسار فرعي. خيارات مجانية:
   - **Netlify Drop**: اسحب مجلد `dist` إلى app.netlify.com/drop.
   - **Cloudflare Pages**: مشروع جديد ← رفع مباشر لمجلد `dist`.
   - **GitHub Pages**: في المستودع workflow `.github/workflows/deploy-pages.yml` يبني ويختبر وينشر عند كل دفع يغيّر التطبيق، أو يدويًا من تبويب Actions. يحتاج مرة واحدة: مستودع عام (أو خطة GitHub تدعم Pages للمستودعات الخاصة)، ثم Settings ← Pages ← Source: **GitHub Actions**، وActions مفعّلة. الرابط: `https://<user>.github.io/<repo>/`.
3. افتح الرابط في Chrome على الهاتف، ثم من القائمة ⋮ اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4. داخل التطبيق افتح **الإعدادات ← البيانات ← تنزيل صور اللعبة** (حوالي 167MB مرة واحدة). عند اكتمال التنزيل تظهر عبارة «جاهز بلا إنترنت».
5. عند نشر إصدار جديد يظهر شريط «نسخة جديدة جاهزة» في وقت آمن، ولا يظهر أثناء عرض تنفيذ جولة. التحديث لا يمسح IndexedDB.

لا يحتاج الخادم إعدادات خاصة. يكفي أن يقدّم `sw.js` و`manifest.webmanifest` بأنواع MIME المعتادة.

## ملاحظات

- مرحلة APK ليست من هذه النسخة. المنطق مفصول عن العرض (engine/store/ui)، فيمكن تغليف التطبيق لاحقًا (مثلًا Capacitor أو TWA).
- لتفاصيل الاستعمال: `docs/USER_GUIDE.md`. لإضافة أبطال وزعماء: `docs/ADDING_CONTENT.md`. لما اختُبر وما لم يُختبر: `docs/TEST_REPORT.md`.
